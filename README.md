## 📄 Descrição do Portfólio
Este projeto consiste no desenvolvimento de um portfólio pessoal moderno e responsivo, construído para a atividade da Agenda do curso técnico em Desenvolvimento de Sistemas da ETEC. O site apresenta minha trajetória acadêmica, habilidades técnicas, links de contato e projetos práticos.

## 💻 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Customizações e estilização visual.
* **Bootstrap 5.3.3:** Framework para layout responsivo, sistema de grid, Carousel e Navbar.
* **Devicon:** Biblioteca de ícones para as tecnologias.
* **Git / GitHub & GitHub Pages:** Controle de versão e hospedagem web.

## ⚙️ Explicação do Funcionamento
O site funciona em página única (*single-page*), estruturado com seções bem definidas:
1. **Carousel:** Destaque visual inicial com slides dinâmicos.
2. **Perfil:** Apresentação pessoal, foto estilizada, resumo e grade com tecnologias dominadas.
3. **Projetos:** Cartões responsivos (*cards*) exibindo os principais trabalhos desenvolvidos.
4. **Contato:** Cartão centralizado com atalhos interativos para e-mail, GitHub e LinkedIn.

## 🚀 Descrição do Recurso Novo Adicionado
* **Recurso:** Efeito visual interativo de *Hover* (elevação e sombra) nos cartões (*cards*) e caixas de tecnologias.
* **Como foi implementado:** Utilizei regras personalizadas em CSS (`transition`, `transform: translateY` e `box-shadow`) ativadas com a pseudo-classe `:hover`, proporcionando uma experiência de navegação mais fluida e moderna.
